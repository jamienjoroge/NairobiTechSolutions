# Sahara Nova website

Static site generated by `build.py` from content in `pages.py`.

- Edit copy, prices or the domain in `pages.py`, then push. Netlify runs `python3 build.py` and publishes `dist/`.
- Local build: `python3 build.py` (no dependencies, Python 3.9+).
- Private test build: `python3 build.py --staging` (noindex everywhere).
- Deploy, DNS and launch notes: `DEPLOY.md`.
